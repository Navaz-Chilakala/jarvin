TasksQueued work, interrupted requests and background commands

    

      
Saved routines

      
Save ordered instructions and run them with the current folder and approval settings. The agent interprets the steps; execution order and results are not guaranteed. Routines are stored locally and shared across folders.

      

      

      
 

      

      

      
Reminders

      
Reminders use your PC's local time. Choose Once, Every day, or Every week. Snoozing delays only the due occurrence. Keep Jarvin open for notifications (checked about every 30 seconds); overdue reminders appear when it next starts. Windows notification settings apply. Reminders are stored locally until removed.

      

      

      
Interrupted and paused requests

      
Some actions may already have happened. Review the request and existing work before continuing; nothing restarts automatically. Task records are stored locally, separately from chat history.

Privacy

  
Prompts and tool results go to the selected model provider. Local Ollama models run on this PC; cloud models and web tools use the network. Chat history and audit logs are stored locally.

  
Auto modes can allow actions without individual approval. Secret redaction is best effort and does not guarantee removal of all private data. Audit log: jarvin-audit.jsonl in user data.

  
  
  
Pausing stops Jarvin's built-in screen and window captures, including the floating pet's screen sampler. The microphone stays available. A screen task already running will stop.

  
  
  
  
  
  
  

  
Jarvin hides excluded windows from its window list and will not control them. If any excluded window is visible, whole-screen capture stops until that window is hidden or the rule is removed. Selected-window captures of other apps remain available. These rules cover Jarvin's built-in tools, not external MCP servers or shell commands.
